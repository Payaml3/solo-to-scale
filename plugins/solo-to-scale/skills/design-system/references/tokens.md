# Tokens

- **One file:** `design/tokens.json`. Groups: `color` (semantic roles only), `font`, `space`, `radius`, `elevation`, `motion`, `breakpoint`.
- **Roles, not values, in code:** components use `var(--color-surface)` or the theme key, never `#fff` or `16px`.
- **Brand mapping:** the palette lives in one `brand` group and maps onto the roles; a rebrand changes only that mapping.
- **Generation:** `tools/build_tokens.py` (standard library) writes each interface's CSS variables or theme file with the header `Generated by solo-to-scale; edit design/tokens.json`, and has a `--check` mode for CI.
- **Changes:** a token change is a design decision (`record-decision`); additive by default, deprecate before removing.
